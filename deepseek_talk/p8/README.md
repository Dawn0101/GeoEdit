## 三句话

1. **PI 指出的三个 bug 全部属实**，逐条用 CSV/掩码审计复现（见 `REPORT_p8.md` §1）：
   合成权重 `M²` 在 GT 区内只有 **0.155**（84.5% 编辑被重置）、振幅放大 **4.56×**、gate **0.0278**。
   致命证据：P7 的 `o5@λ=1` CLIP-E **20.127** 低于不编辑的 **20.255**。
2. **修完后**：λ=1 的 CLIP-E **21.14**（P7 20.13），背景 PSNR **23.42**（ChordEdit 22.02），
   全图 DINO **0.021**（ChordEdit 0.031）。**VLM 配对仍落后 0.78 nat（胜率 34%）**；
   匹配全图 DINO 后落后 **0.56**（胜率 38%）。P7 是 −2.44。
3. **SDS 项仍有效**：k=1 比 k=0 高 **+0.22 nat（胜率 65%）**，代价 PSNR 25.60→23.42。
   修正后 masked prox ≈ full prox（−0.06，CI 含 0）⇒ P7 那条"掩码合成吃编辑"的结论**作废**。
