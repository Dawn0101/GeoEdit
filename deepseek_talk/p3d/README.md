## 一句话结论

**按 §5 的去留规则：D1b 不成立 + D2b 未通过 ⇒ 方法线收掉，不开 P4。**
唯一正面结论：同一个 λ、同样幅度下，**挑一个样本比平均保留多 28% 的 CLIP-D**
（+0.0156 [+0.0110, +0.0202]），但匹配 CLIP-D 的前沿上不占优（平均把 λ 调大就能补回来）。
模型自己的似然比验证器没有语义信息：带符号 Δℓ 逐像素 AUROC **0.51**、整图挑选与随机无异。

## 四条口径提醒

1. **同 λ ≠ 同幅度**。λ=1 时 ‖δ‖/λ：V0 66.0、挑一个 56.1、混合 35.7、平均 35.2、8 次平均 18.1。
   所有"同 λ 比较"都要看这一列。
2. **CLIP-Edited 不敏感**。单图换 seed 的 σ ≈ 1.5（由 CLIP oracle +1.58 ≈ 1.03σ 反推），
   而方法间只差 0.1–0.3。判定语义请用 **CLIP-D**。
3. **D1b 的 H1-5 vs V1x 只有 304/2000 次重采样同时覆盖锚点**（V1x 的 CLIP-D 最高 0.054，几乎摸不到 0.0559）。
4. **V2 的 CLIP-D 掉了 21%，几乎全部来自 category 3（delete_object）：0.008 vs 0.042**。
   改背景/改风格两类几乎无损（0.90 / 1.00）——与"集中在全局编辑"的猜测相反。
