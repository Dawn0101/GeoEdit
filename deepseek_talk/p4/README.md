## 两条判定

1. **第 0 步 = STOP**：`P6pair` 的 AUROC 在 t=0.9/0.7/0.5 = **0.534 / 0.571 / 0.648**，
   三个 t 全部 < 0.7（门槛 0.8）；而能量 `E` 是 0.781/0.855/0.858。
   ⇒ 闭环第 1 轮能拿到的证据（P1pair = 0.52）与瞎猜无异，按 §3.2 不写闭环代码。
2. **指标效度 = 幅度计**：错 prompt 的每单位 CLIP-D 是 V0 的 **73%**、纯噪声 **41%**
   （门槛 <25%），反向编辑也不为负 ⇒ **CLIP-D 主要度量幅度，不是语义**。

## E1d：真正的语义评委说了什么

用本地 EditReward（Qwen2.5-VL-7B + 两个 reward head），**所有变体缩放到相同编辑范数**后：

| 点 | dim1（指令遵循）| 与 V0 的配对差 |
|---|---|---|
| src（不编辑）| 0.792 | — |
| V2（GT mask）| 0.209 | **+0.103 [+0.071, +0.137]** |
| V12 | 0.113 | +0.008 [−0.013, +0.030] |
| V0 | 0.106 | — |
| V1（平均）| 0.105 | −0.000 [−0.028, +0.029] |
| S3-5（挑一个）| 0.101 | −0.005 [−0.025, +0.015] |

**平均 vs 挑选：−0.005 [−0.032, +0.023]** → 在匹配幅度下**没有差别**。
只有当 oracle GT mask 存在时评委才真的更喜欢（+0.103），学到的 mask 与不 mask 无差别。

## 由此产生的更正（重要）

P3d 的 **D1a（"挑选择多保留 28% CLIP-D"）不成立**：同 λ 下挑一个的幅度是平均的 1.6 倍
（‖δ‖/λ：56.1 vs 35.2），按单位幅度归一后
`S3-5 − V1 = −0.079e-3 [−0.201, +0.036]`（点估计为负、CI 含 0）。
**D1b（前沿不变）与 D2（验证器无信息）不受影响。**

## 三条口径提醒

1. **不要再用 CLIP-D 做语义匹配**。P3d-D1a 已撤回；后续语义结论要么用**单位幅度**归一，
   要么用 E1d 的 VLM 评委。
2. 第 0 步的失败是**信息量层面**的（系统部分占能量 3–5%，编辑区内外只差 2–3 倍），
   换 K/η/α/τ 都改不了"第 1 轮 0.52"这件事。
3. α = 0.944 是在独立 50 张上用 GT 一次性校准的（文档 §3.3 允许）；但内外只差 2 倍、
   AUROC 0.52，α 实际落在噪声里。
