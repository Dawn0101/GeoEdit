## 1. 第 0 步：闭环的确认信号在离线数据上不存在

数据：540 张图（类别 0–7），复用 P1/P3a 的 fp32 残差（4 seed × t∈{0.5,0.7,0.9}），**无新前向**。
统计量：`pool3(⟨R_i, R_j⟩)`（i≠j 的跨噪声内积 = 残差的**系统部分**），1/3/6 对平均。
对照：`E` = DiffEdit 式平均能量。

| 统计量 | t=0.9 | t=0.7 | t=0.5 |
|---|---|---|---|
| P1pair（≈闭环 1 轮的证据量）| 0.521 | 0.548 | 0.590 |
| P3pair | 0.535 | 0.561 | 0.627 |
| **P6pair（4 seed 的全部 6 对）** | **0.534** | **0.571** | **0.648** |
| E（能量，参照）| 0.781 | 0.855 | 0.858 |
| X（跨尺度 ⟨R₀.₉, R₀.₅⟩，4×4 对）| 0.543 | — | — |
| Ratio（‖R₀.₅‖/‖R₀.₉‖）| 0.642 | — | — |

（中位数，n=484；完整分位数见 `p4_step0_auroc.csv`）

**读法**：

1. **6 对也只有 0.53–0.65**，而**总能量**有 0.78–0.86。闭环第 1 轮能拿到的证据（1 对）是 0.52，
   **和瞎猜没有区别**——它分不清前景和背景，所以"被确认的改动保留、没被确认的扣租金"这个机制
   从第一步起就没有信息可用。
2. 从 1 对加到 6 对，AUROC 只涨 0.01（t=0.9）到 0.06（t=0.5）：**靠多抽噪声救不回来**，
   因为系统部分只占能量的 3–5%（P3a 方差分解：随机占比 0.95–0.97），而它在编辑区内外只差 2–3 倍。
3. 跨尺度内积 X（0.543）和幅度比 Ratio（0.642）也都不够。**没有哪一项接近 0.8 的 GO 门槛。**
4. 与交接文档"已知风险"的预判一致：闭环唯一的翻盘机会是**实例锁定**（H3），而 H3 只有在进入第 1 步后
   才能测；第 0 步既然已经否掉了"第 1 轮有信号"，按纪律就停在报告。

**α 校准（§3.3，照做）**：在**另外 50 张**（与评测 200 张不重叠，固定种子抽取，id 见
`p4_alpha_calib.json`）上，1 对 seed、t=0.9 的归一化得分在 GT 内/外均值：

```
μ_in = 1.267     μ_out = 0.620     α = (μ_in + μ_out)/2 = 0.944
```

参考价值有限：内外只差 2 倍，而 AUROC 0.52 —— α 落在噪声里。**GT 只在这次校准里用了一次**，
评测集上未用 GT 调任何东西。

## 2. 指标效度：CLIP-D 是"幅度计"

数据：540 张图，t=0.9，λ∈{0.5, 1, 2}；三个对照都用本图**正确的** prompt 对评测。

| 变体 | 构造 | 每单位幅度的 CLIP-D（λ=1，×1e-3）| 相对 V0（配对 bootstrap）|
|---|---|---|---|
| V0 | λ·R₀ | **0.832** | — |
| **E1a** | 用**另一张图**的目标 prompt 算残差（随机置换，排除同类别，+2 前向/图）| **0.610** | **0.73 [0.68, 0.79]** |
| **E1b** | δ = λ·\|R₀\|⊙ξ（同包络、同范数的高斯噪声）| **0.344** | **0.41 [0.37, 0.46]** |
| E1c | δ = −λ·R₀（反向）| 0.250 | 0.30 |

判定（§5）：E1a、E1b 的每单位 CLIP-D 必须 < V0 的 **25%**，且 E1c 为负。
实测 **73% / 41%**，E1c 的每单位 CLIP-D 仍是**正的** 0.25×10⁻³（不是负的）→ **CLIP-D 判为幅度计。**

**为什么这件事重要**：一个"改错了方向"的编辑（E1a）能拿到正确编辑 **73%** 的 CLIP-D；
纯粹的高斯噪声（E1b）也有 **41%**。说明 CLIP-D 主要度量的是"latent 被移动了多少"，
"移动的方向对不对"只占很小一部分。**所有基于 CLIP-D 的语义结论都必须重新审视。**

## 3. 对 P3d 的更正：D1a 是幅度效应，不成立

P3d 的 D1a 用的是**同 λ** 比较：CLIP-D(S3-5) − CLIP-D(V1) = +0.0156 [+0.0110, +0.0202]。
但同 λ 下两者的**幅度不同**（λ=1 时 ‖δ‖/λ：S3-5 **56.1** vs V1 **35.2**，1.6 倍）。
既然 CLIP-D 是幅度计，就必须按单位幅度归一再看：

| 变体 | 每单位幅度的 CLIP-D（×10⁻³）|
|---|---|
| V0（单个 seed）| 0.832 |
| V1（4 seed 平均）| 0.948 |
| S3-5（挑一个，16 NFE）| 0.869 |
| S3-9（挑一个，8 NFE）| 0.879 |
| H1-9（混合，8 NFE）| 1.030 |
| V12 | 1.166 |
| V1x（8 残差平均）| 1.105 |

配对 bootstrap（λ=1，n=540）：

```
每单位 S3-5 − V1 = −0.079e-3  [−0.201, +0.036]     ← 点估计为负，CI 含 0
每单位 H1-9 − V1 = +0.081e-3  [+0.000, +0.161]     ← 边缘
每单位 V1   − V0 = +0.116e-3  [−0.001, +0.241]     ← 边缘
```

**结论：按单位幅度，挑选并不比平均更"有语义"（点估计甚至是负的）。**
D1a 的正号来自"挑一个的幅度更大"，不是来自"挑一个更能表达目标"。
P3d 的 D1b（匹配前沿后混合不占优）不受影响——它本来就说"前沿不变"，现在只是原因更清楚了：
**平均与挑选的差别整体上是幅度/前沿的再参数化，而不是语义质量。**
