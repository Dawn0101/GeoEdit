## 1. 掩码修正：平顶 + 单次门控

P9 的掩码是 `q60/q90` 分位归一，且**在 transport 与最终合成各乘一次**；物体内部均值 0.61，
于是内部只保留 `0.61²≈0.37` 的编辑量。本轮改为：

```
E  = Gaussian(‖R(t)‖, σ=2)
M_plat = clip((E − q40) / (q65 − q40), 0, 1)      # top 35% 严格饱和为 1.0
```

- **只在最终输出乘一次**（`out = (1−M)x_s + M·prox`）或**只在 transport 乘一次**（`δ = M·u`），
  绝不同时乘。
- 实测掩码统计（200 图均值）：`M>0.5` 面积 **0.464**、GT 内均值 **0.67**、GT 外 **0.41**
  （P9 的 q60/q90 是 0.202 / 0.61 / 0.166 —— 平顶版覆盖更满、内部更饱和）。

| 变体 | 背景 PSNR | LPIPS | DINO | **CLIP-E** |
|---|---|---|---|---|
| 官方（无掩码） | 22.02 | 0.125 | 0.031 | **22.57** |
| P9：软掩码 + 双次门控 | 27.38 | 0.043 | 0.008 | **20.99** |
| **P10：平顶 + 仅最终单次门控** | **23.84** | 0.081 | 0.021 | **22.23** |
| P10：平顶 + 仅 transport 单次门控 | 22.50 | 0.118 | 0.028 | 22.23 |

⇒ **消除二次衰减拿回 +1.24 CLIP-E**（PI 的判断正确），但仍比官方低 0.34 —— 因为事后乘掩码
只能截断背景，**无法增强掩码内部的语义**。这正是要把引导前移到 UNet 内部的理由。

## 2. 层内引导的实现（`geoedit/inlayer.py`）

只改**目标分支**的 `attn2`（16 层）。每次调用给出 `(Q, c_tar, c_src, M)`：

- Q 只算一次；`O_tar = softmax(Q·K_tarᵀ/√d)·V_tar`、`O_src` 同式 —— **共享 Q，0 跨分支噪声**；
- 用当前层分辨率的掩码 `m`（64→64/32/16/8 双线性）调制；
- 关闭时走原 `AttnProcessor2_0`（已验证**逐位相同**：`maxdiff = 0.0`）。

掩码来源（0 额外 NFE）：`t=0.9` 的两支算完后得 `M_0.9` → 引导 `t=0.75` 的目标支；
`t=0.75` 的两支算完后得 `M_0.75` → 引导 prox(0.3)。

**SCAD**（我们的方案）：`ΔO = O_tar − O_src`
- **A**：`O~ = O_tar + α·m·ΔO`
- **B**：`O~ = O_src + (1+α)·m·ΔO`

**MGA**（文献对照）：`logits[:, :, E_tar] += λ·(m − mean(m))`，`E_tar` = 目标 prompt 相对源
prompt 的新增/替换 token（对比 token id 序列求得，删除类为空则不加偏置）。

有效性自检（单张图，`t=0.75`，掩码取中间方块）：SCAD-A 掩码内变化 / 掩码外 = **3.05×**、
SCAD-B **1.72×**、MGA **3.45×**，说明调制确实集中在掩码内。

| **官方（ChordEdit）** | 22.02 | 0.125 | 0.031 | **22.57** |

| plat_trans | 22.50 | 0.118 | 0.028 | 22.23 |
| mga4_mask（MGA + 事后掩码） | 23.58 | 0.083 | 0.022 | 22.19 |

**读法**：

1. **SCAD-A α=1 是唯一在四项指标上同时超过官方的配置**（CLIP-E +0.38、PSNR +0.61 dB、
   LPIPS −25%、DINO −16%）。这是本项目到目前第一次在语义轴上不输、且保真更好。
2. **SCAD-B 与 A 同档**，但 B 的 PSNR 更高（22.92）、CLIP-E 略低（22.91）——B 在掩码外直接喂
   源文本特征，背景更稳，符合设计意图。
3. **α 的单调性**：0.5 → 22.74、1.0 → **22.95**、2.0 → 22.88，即 α=1 是甜点，α=2 开始掉
   （与 P6 里 k 的规律一致：推过头就毁）。
4. **MGA 无效**：λ 从 2 到 8，CLIP-E 22.57→22.55，PSNR 单调下降。机制上说得通 —— 它只改变
   **目标词列的注意力分配比例**，而我们的 SCAD 直接放大**特征差分**，后者与"语义注入量"更直接。
5. **两者不叠加**：SCAD+MGA 22.71 < SCAD 单独 22.95。MGA 的 logit 偏置与 SCAD 的特征放大
   在同一个 softmax 上竞争，叠加后反而互相抵消。
6. **事后掩码对 MGA 有害**（mga4_mask 22.19 vs mga4_nomask 22.60），对 SCAD 则是可选的
   保真旋钮（scadA_a05 的 PSNR 23.11 / CLIP-E 22.74）。

## 5. 结论

1. **层内引导是对的**：把"掩码只能截断背景"变成"在 UNet 内部把文本语义注入的能量按空间重分配"，
   **SCAD-A（α=1）在四项指标上全面超过官方 ChordEdit**，VLM 配对 +0.31（胜率 61%）。
2. **PI 的两条诊断都被证实**：
   - 双重软掩码使内部只保留 `0.61²≈0.37` 的编辑量 —— 改成平顶 + 单次门控拿回 **+1.24 CLIP-E**；
   - 事后乘掩码无法增强内部语义 —— 必须前移到 `attn2`，SCAD 再拿回 **+0.72 CLIP-E**（22.23→22.95）。
3. **MGA 在这个任务上无效**（λ 从 2 到 8 都 ≈ 官方水平），且与 SCAD **不可叠加**（22.71 < 22.95）。
   这意味着 SCAD 的"特征输出差分放大"比 MGA 的"目标词 logit 偏置"更直接有效。
4. **SCAD 是 token-free 的**：不需要找编辑词、不需要 `[ ]` 标注，添加/删除/替换一视同仁。

## 6. 下一步（P11 建议）

1. **SCAD 与 ChordEdit 的时间弦是否互补**：目前 SCAD 只在 `t=0.75` 与 `prox` 上生效，可试
   同时在 `t=0.9` 上生效（用 `M_0.9` 之前先用一次 `E_0.9` 的自举）。
2. **α 的逐图自适应**：用 `‖ΔO‖` 在掩码内的能量做归一，避免固定 α 在强/弱编辑图上过冲/不足。
3. **SCAD 的 NFE 账**：本轮 SCAD 的 `attn2` 多算一次 `O_src`，前向次数不变（仍 5 次），但
   注意力 FLOPs 约 +1×（cross-attn 占 UNet 不到 1%），实测每图耗时 11 s（与官方同量级）。
4. **换更大数据集验证**：200 图上的 +0.31 需要 700 图复现才能写进论文。
