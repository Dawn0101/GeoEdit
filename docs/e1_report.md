# E1 — proposal 背景偏差的性质：几何错位还是重绘？

- 日期：2026-11-24
- 数据：PIE-Bench 700 张，两个 proposal 源（B0 = 仅 transport，B1 = transport + prox）
- 代码：`scripts/run_e1.py`；原始数据 `results/E1/per_patch.csv`（23,704 行）；汇总 `results/E1/report.json`

## 1. 口径

- 背景 = GT mask 的补集，在 64×64 latent 网格上**腐蚀 2 格**（= 16 图像像素）。
- 单位：8×8 latent patch（= 64×64 图像像素），700 张共 **11,852 个背景 patch / 每个 proposal**。
- `r0` = 零位移的 `mean((y − x_src)²)`（scaled latent，逐元素）。
- `r*` = 位移 ∈ [−3,3]² 内块匹配的最小值。
- `gain` = `1 − r*/r0`：刚性平移能解释的残差比例。`shift≠0` 且 `gain>0.2` 记为"显著位移"。
- `drift_ratio` = 残差经过 σ=2 低通后的能量占比：**低** = 高频重绘，**高** = 低频色调漂移。
- `dino_dist` = 解码图上 DINOv2 patch 特征的余弦距离（448 → 32×32，在每个 8×8 latent patch 内平均）。
- `fp_rate` = 背景 token 中被逐点阈值（`R=0`）判成"要改"的比例，`2τ ∈ {2,4,8}`。

## 2. 主结果

| 指标 | **B0**（仅 transport） | **B1**（+ prox） |
|---|---|---|
| 显著位移 patch 占比 | **0.03 %** | **1.58 %** |
| 最优位移 ≠ 0 的占比 | 1.26 % | 6.99 % |
| `gain` p50 / p90 | 0.000 / 0.000 | 0.000 / 0.000 |
| `r0` p25 / p50 / p75 / p90 | 0.020 / 0.072 / 0.185 / 0.344 | 0.139 / 0.217 / 0.315 / 0.439 |
| `drift_ratio` p25 / p50 / p75 / p90 | 0.077 / **0.149** / 0.291 / 0.521 | 0.042 / **0.067** / 0.114 / 0.194 |
| `dino_dist` p50 | 0.254 | 0.352 |
| 背景误判率 `2τ=2` / `4` / `8` | **32.7 %** / 19.2 % / 10.4 % | **17.5 %** / 5.1 % / 1.8 % |

按 10 个类别的 `frac_significant`（B0 → B1），最高的是 change style `9` 类
0.00 % → 11.4 %（该类 GT mask 几乎覆盖全图，只剩 44 个背景 patch，统计量很小），
其余 9 类全部 ≤ 3.2 %。

## 3. 判定

原计划的判定规则是：`显著位移占比 < 10% 且 gain 中位数 < 0.1` → 偏差主要是重绘或色调漂移，
空间容忍没有发挥空间。**实测 0.03% / 1.58%，远低于 10% 的门槛，而且 `gain` 的中位数和 p90
都是 0.000 —— 块匹配连"部分解释"都做不到：在 ≥90% 的背景 patch 上，零位移就是最优解。**

进一步，`drift_ratio` 的中位数只有 14.9%（B0）和 6.7%（B1）：残差能量的 85–93% 在**高频**。
所以也不是"色调/亮度整体漂移"这种低频谱错误。

**结论：ChordEdit 的背景偏差既不是几何错位，也不是低频漂移，而是高频纹理重绘**
——一步 x0-difference 在背景上重新写了细粒度细节。DINO 距离中位数 0.25–0.35 说明这种
重绘在语义层面也是可测的，不只是像素噪声。

## 4. 对方法的影响（这是 E1 真正要说的话）

1. **部分 OT 的空间容忍没有可发挥的余量。** `r_max = s_p√(2τ)` 这条可解释性卖点，
   面对一个 `gain = 0` 的残差场是空转：允许 ±5 格搬运，最优解就在 0 格。
2. **逐点阈值也不好用。** 想在面积上匹配 GT（`2τ≈2`），B0 会误判 32.7% 的背景 token，
   B1 误判 17.5%。这与直接用 σ 得到的 IoU ≈ 0.41 完全一致 —— 背景和编辑区在"残差幅度"
   这个特征上**不可分**，加空间容忍也不会让它们变可分。
3. **唯一可能有效的方向是换表示/换特征**，让代价对高频重绘不敏感（强低通、粗尺度、
   更大的 patch、或语义特征），而不是换传输模型。这与"OT 是装饰性的"这个判断互相印证：
   起作用的是**代价函数**，不是**传输**。
4. 顺带解释了为什么"像素域/掩码合成"类方法在 PIE-Bench 上总是 PSNR 虚高：
   只要 mask 覆盖住背景，指标就送分；而这张 mask 其实覆盖错了三成背景（B0）。

## 5. 需要注意的口径局限

- 块匹配只测**刚性平移**。自由形变（非刚性）能解释多少没有测；但部分 OT 的二次空间代价
  给出的也是"局部平移"这一族解释，所以这个局限对本文的结论影响不大。
- patch 固定 8×8，小于 8 格的位移会被 patch 内部平均掉一部分；把 patch 缩小会让
  `frac_moved` 升一些，但 `gain` 的量级（0.000）不会变。
- latent 残差是 scaled latent 下的逐元素 MSE，与图像域 PSNR 不是线性对应；
  这里只用来比较 `r0` 与 `r*` 的相对大小。
