## Idea

文本引导图像编辑要同时满足"背景保持"与"目标对齐"。ChordEdit（ICCV/CVPR 2026）用一步
x0-difference 得到一个 proposal `y`，它不保证非编辑区不变。v1 的想法是把"哪里该改"
写成一个**部分最优传输**问题，用它的边际当软 mask：

- 源 token `(p_i, f_i)` 与 proposal token `(q_j, g_j)` 在同一 64×64 网格上，质量均匀 `a=b=1/N`；
- 代价 `C_ij = ‖f_i−g_j‖²/s_f² + ‖p_i−q_j‖²/s_p²`（特征 + 空间，窗口 `|o|_∞ ≤ R`）；
- 目标 `min ⟨C,P⟩ + τ(|a|−|P|) + τ(|b|−|P|)`：`τ` 是**销毁/新建质量的单价**，
  `C_ij > 2τ ⟹ P_ij = 0`，最大可搬运半径 `r_max = s_p√(2τ)`；
- 读出 `σ_j = (Pᵀ1)_j / b_j`，输出 `z = σ⊙x_src + (1−σ)⊙y`，prox 只作用在编辑区，总 NFE = 2（与 ChordEdit 相同）；
- `s_p → 0` 退化成逐点残差阈值，所以"点阈值 mask"是本方法的一个特例，消融干净。

卖点原本是三条：可解释的价格 `τ`、允许跨位置匹配（对几何错位鲁棒）、退化成已知方法。

## 为什么失败

**① 传输计划根本没被用到。** 输出只需要边际 `σ`，计划的联合结构被丢掉；`ε→0` 时
`σ_j ≈ 1[min_o(‖f_j−g_{j+o}‖²/s_f² + ‖o‖²/s_p²) < 2τ]`，即**带位移容差的块匹配阈值**。
把"部分 OT"换成"窗口最小距离阈值"不需要改任何其它部分——OT 是可替换的模块。

**② E1 实测：空间容忍没有余量。** 700 张 PIE-Bench、每个 proposal 11,852 个背景 patch（8×8 latent，腐蚀 2 格）：

| 指标 | B0（仅 transport） | B1（+ prox） |
|---|---|---|
| 显著位移 patch 占比（shift≠0 且 gain>0.2） | **0.03 %** | **1.58 %** |
| `gain` p50 / p90 | 0.000 / 0.000 | 0.000 / 0.000 |
| 残差中低频能量占比 `drift_ratio` p50 | 0.149 | 0.067 |
| 背景误判率 `2τ=2 / 4 / 8` | 32.7 % / 19.2 % / 10.4 % | 17.5 % / 5.1 % / 1.8 % |

`gain` 的中位数与 p90 **都是 0**：在 ≥90% 的背景 patch 上零位移就是最优解。残差能量的
85–93% 在高频——偏差是**纹理重绘**，不是几何错位、也不是低频色漂。`r_max` 这个卖点面对
`gain = 0` 的残差场是空转。

**③ 逐点阈值同样不可分。** 面积匹配 GT 时背景误判 32.7%/17.5%，与 σ 直接得到的
IoU ≈ 0.41 自洽：背景与编辑区在"残差幅度"上本来就不可分。

## 仍然有价值的产出

- **E0 基线**：ChordEdit 复现，PSNR(unedit) 23.58/22.45 vs 论文 23.89/22.20，
  LPIPS 0.0878/0.121 vs 0.0884/0.1283 → 底座可信，且证明了 CLIP 分数不可跨论文比较
  （同一张图，`0–255` 输入 27.39、`0–1` 输入 17.52，差 9.9 分）。见 `docs/baseline.md`。
- **E1 数据**：23,704 行背景 patch 的 `r0 / r* / gain / 最优位移 / 低频占比 / DINO 余弦`，
  任何后续方法都要面对这条约束。
- **求解器**：`src/geoedit/uot.py`，窗口 + 稠密双实现，20 项单测（含与 LP 精确解交叉验证、
  阈值性质、`R=0` 退化、`τ` 端点、极值数值稳定性）。换到别的部分 OT 问题可直接复用。
- **报告**：`docs/DECISION.md`（决策记录）、`docs/e1_report.md`（诊断全文）、`results/E1/`、`figures/`。
