> 取代 `claude_to_deepseek_geoedit_20261125_v3_p3e.md`。P3e 的 E1（指标效度）并入本文 §5，E2–E4 暂停。

> 纪律不变：方法内部不用 CLIP，也不用 GT；oracle 只作参照；判定阈值先写定；所有结果全部报告，不挑 seed。

---

## 0. 为什么做这个

1. P3d 加上复查表明：在相同语义（CLIP-D）下，平均、挑选、调 λ、Picard 都落在同一条曲线上；只有改变编辑的**空间分布**才能移动前沿。在相同语义下，GT mask 比 V0 高约 7 dB，现有开环 mask（V12）只高约 1 dB。
2. 现有一步编辑的 mask（DiffEdit、BudEdit、PreciseEdit、WhereEdit、ER-Chord）都是**开环**的：只在原图上看一次模型的反应就定下来，从不检验编辑结果。
3. P4 检验**闭环**：同时维护内容和 mask，每一轮都把当前编辑结果加上新噪声送回模型"验货"。被检验确认的改动保留，没被确认的退回原图。

**已知风险（写在前面）**：闭环的确认信号只来自残差的**系统部分**。不同噪声的随机部分互不相关，内积平均为 0。而系统部分只占能量的 3–5%（`p3a_variance_medians.csv`），在编辑区内外只相差 2–3 倍。所以闭环能否赢过开环能量 mask（AUROC 0.858），关键在于是否出现**实例锁定**：模型看到改了一半的图后，在编辑区给出的方向越来越一致。第 0 步和 H3 就是用来检验这一点的。

---

## 1. 记号

- x_s：原图 latent；c_src、c_tar：源 prompt 和目标 prompt。
- 噪声强度 τ 下的加噪：z = a_τ·x + b_τ·ε，与 P1/P2 的 `edit_ops.py` 完全一致。
- D(z, c)：模型的去噪预测 x̂，口径同 P1/P2 中的 `residual(...)`。
- 内容 d = x − x_s（"如果允许改，要改成什么"）；mask m ∈ [0,1]^{64×64}（"允许改多少"），在 4 个通道上广播。
- 当前成品：y = x_s + m⊙d。
- 逐像素内积 ⟨u_p, v_p⟩：在 4 个通道上求和。pool3 表示 3×3 均值池化（stride 1，same padding）。

---

## 2. 算法

```
输入：x_s, c_src, c_tar, λ, K, η_x, η_m, α, k(=0)
# 初始化 = 一步编辑 V0（与 P1 存档的 t=0.9、seed 0 残差逐元素相同）
R0 = D(a·x_s + b·ε0, c_tar) − D(a·x_s + b·ε0, c_src)   # τ=0.9，ε0 = make_eps(id, seed=0)
d = λ·R0;  m = 1

for t = 1..K:
    τ_t = max(0.5, 0.9 − 0.1·t)                 # 0.8, 0.7, 0.6, 0.5, 0.5, …（与 K 无关，便于共享前缀）
    ε_t = make_eps(id, seed=100+t)              # 每轮新噪声；两个分支共用
    y = x_s + m⊙d
    R = D(a·y + b·ε_t, c_tar) − D(a·x_s + b·ε_t, c_src)
    # ① 内容：回归到 λR（只在 mask 内）
    g = λ·R − (y − x_s)
    if k>0:  g += k · m^2 ⊙ (D(a·y + b·ε_t, c_tar) − y)       # SDS 只在核心区开（第二阶段）
    d = d + η_x · m ⊙ g
    # ② mask：被确认的保留，没被确认的扣"租金"
    s = pool3(<R_p, d_p>)                       # 用 R，不用 g（理由见 §2.1）
    s = s / (median_q |s_q| + 1e-8)             # 以背景典型幅度为单位，α 无量纲
    m = clip(m + η_m · (s − α), 0, 1)
    保存前缀：y_t, m_t, 诊断量

输出：decode(y_K)，以及 m_K
```

- NFE = 2 + 2K。源分支每轮都要重算，因为 ε_t 变了。不需要对 UNet 反传。
- **τ 的安排与 K 无关**：跑一次 K=16 并保存每一轮的前缀，就得到 K ∈ {2, 4, 8, 16} 的全部结果。

### 2.1 两处容易写错的地方（不要改）

1. **mask 的得分用 ⟨R, d⟩，不用 ⟨g, d⟩。**
   - ⟨g, d⟩ = ⟨λR, d⟩ − m‖d‖²。第二项是 d 和自己求内积，d 里约 97% 的随机能量会被全额扣掉，改得越多的地方扣得越多，第一轮就会把前景砍掉。
   - 如果严格按回归损失对 m 求导，最优值是 S/(S+V)，而这个比例在编辑区内外几乎相同（96.8% vs 97.3% 为随机部分），等于又掉进 SNR 的陷阱。
2. **g 里要乘 λ。**
   - 不乘的话，λ 会在后续轮次中被 −(y − x_s) 洗掉。
   - 注意：P2 的 c≈1 是在固定 ε 的 Picard 下测得的，**不适用于**每轮换噪声的情形。

### 2.2 默认超参

| 参数 | 默认 | 说明 |
|---|---|---|
| λ | 扫 {1, 1.5, 2, 3} | 用于匹配语义。预期幅度会逐轮缩小，所以需要比 V0 更大的 λ |
| η_x | 0.25 | |
| η_m | 0.25 | 第 1 步在 K=8 下另扫 {0.1, 0.5} |
| α | 在校准集上定（§3.3），另扫 ×{0.5, 2} | |
| k | 0 | SDS 放到第二阶段（§4.5） |

## 3. 第 0 步：离线预检（不需要新前向，当天出结果）

复用 P1 存的残差（每张图在 t ∈ {0.5, 0.7, 0.9} 下各 4 个 seed），540 张图（类别 0–7）。

### 3.1 统计量与 AUROC（对 GT mask，连续值）

| 记号 | 定义 |
|---|---|
| P1pair / P3pair / P6pair | 用 1 对、3 对、6 对 seed 的 pool3(⟨R_i, R_j⟩)（i≠j）求平均。**1 对约等于闭环 1 轮的证据量**，用来预估闭环需要几轮 |
| X | 跨尺度内积 pool3(⟨R(0.9)_i, R(0.5)_j⟩)，i、j 取遍 4×4 |
| Ratio | ‖R(0.5)‖ / ‖R(0.9)‖（各自取 4 seed 的平均能量，再开方相除，加 pool3） |
| E（参照） | DiffEdit 式平均能量（P3d：0.858 / 0.855 / 0.781） |

每项在 3 个 t 下都要报（X 和 Ratio 除外，它们本身就跨 t）。

### 3.2 判定（预注册）

| 结果 | 结论 |
|---|---|
| t=0.9 时 P6pair 的 AUROC ≥ 0.8 | 闭环有可用信号，进入第 1 步 |
| P6pair 的 AUROC < 0.7（三个 t 都如此） | 停止。闭环在第一轮就分不清前景和背景，不写闭环代码，写报告 |
| 介于两者之间 | 照常进入第 1 步，但 H3（实例锁定）升为主判据，并在报告里写明 |

另外报告 P1pair → P3pair → P6pair 的 AUROC 增长曲线：如果 6 对仍明显低于 E，就说明闭环只能靠实例锁定翻盘。

### 3.3 α 的校准

- 从类别 0–7 中**另取 50 张图作为校准集**，与评测用的 200 张不重叠，固定种子抽取并列出 id。
- 在校准集上，计算 1 对 seed（t=0.9）的归一化得分 s 在 GT 编辑区内、外的均值，记作 μ_in、μ_out。默认 α = (μ_in + μ_out)/2。
- **这是在独立校准集上用 GT 调一个超参**，必须在报告里明说；评测集上不得再用 GT 调任何东西。

## 4. 第 1 步：闭环主实验（需要新前向）

### 4.1 数据

- 评测集：类别 0–7 中固定种子抽取的 200 张，优先沿用判据①的那 200 张，去掉类别 8、9；不够的部分补抽，列出 id。
- 校准集：§3.3 的 50 张。

### 4.2 变体与对照

主方法：K ∈ {2, 4, 8, 16}（一次 K=16 的运行保存前缀）× λ ∈ {1, 1.5, 2, 3}。

| 记号 | 设置 | 检验的问题 | λ |
|---|---|---|---|
| **Main** | 如 §2 | — | 全部 |
| C1 | m 固定为 1（只更新内容） | mask 是否必要 | {1.5, 2} |
| C2 | d 固定为 λR0（只学 mask；输出 x_s + m⊙λR0） | 更新内容是否必要；同时也是"给单步编辑用的闭环定位器" | 全部 |
| C3 | 每轮都用 ε0（不换噪声） | "换噪声验货"是否必要。预期背景的 m 降不下去 | {1.5, 2} |
| C6 | τ 固定 0.9（不退火） | 由粗到细的退火是否有用 | {1.5, 2} |
| **C8** | **开环同统计量**：在 x_s 上抽 K 个新噪声，算 pool3 两两内积的平均，按 §2 的规则归一化，m = clip(1 + η_m·K·(s̄ − α), 0, 1)，输出 x_s + m⊙λR0 | **最关键的对照**：区分"闭环反馈"和"多抽几次噪声的统计量"。NFE 与 Main 相同 | 全部 |
| V0、V12、V1x | 复用 P3d | 基线 | 已有 |
| V2 | GT mask | 上限 | 已有 |

C8 的 NFE = 2 + 2K，与 Main 对齐。如果 Main 赢不了 C8，"闭环"就没有贡献。

### 4.3 每一轮记录的诊断量

- m_t 对 GT 的 AUROC，以及 mean(m_t)；
- 编辑区和背景里，相邻两轮 R 的余弦 cos(R_t, R_{t−1})：逐像素求内积再在区域内求和，然后除以区域内两者的范数；
- 编辑区和背景里的幅度 ‖m⊙d‖，并与第 0 轮比较；
- ‖g‖、得分 s 在编辑区内外的均值。

**幅度的理论参照**：如果没有实例锁定（各轮 R 互相独立），η_x=0.25 时内容是各轮 λR 的移动平均，编辑区幅度会收敛到初始值的约 0.4 倍（系统部分占比 3% 时，√(0.03 + 0.97×0.143) ≈ 0.41）。

### 4.4 预注册假设

匹配语义的方法沿用 P3d：image-level bootstrap 2000 次；沿 λ 在均值层面线性插值，不外推；锚点附近不单调时只报同 λ 的结果。

- **H1（主假设）**：在 CLIP-D = 0.040、NFE ≤ 18（K ≤ 8）的条件下：
  - (a) Main 相对 V12 的背景 PSNR ≥ +1.5 dB，且 CI 不含 0；
  - (b) Main 相对 C8（相同 K、相同 NFE）≥ +1.0 dB，且 CI 不含 0。
  - 锚点 0.0559 能覆盖时一并报告，但不参与判定。
- **H2**：m 的 AUROC 随轮数单调上升，且 K=8 时 > 0.858。
- **H3（机制：实例锁定）**：
  - (a) 第 4 轮时，编辑区相邻两轮 R 的余弦 > 0.3，背景 ≤ 0.15；
  - (b) K=8 时，编辑区幅度 ≥ 第 0 轮的 0.7 倍（无锁定时的理论值约为 0.41）。
- 同时报告 Main 相对 C1、C2、C3、C6 的 ΔPSNR（同一锚点），不做判定，用于消融表。

### 4.5 第二阶段（只有 H1 成立才跑）：SDS

- Main 加 k ∈ {1, 2}（跟 mask 走，m² 门控）；C5 为 k=2 且不门控（g += k·(D(·) − y)）。
- 按类别报告，重点看加物体（2）、改姿势（5）、换物体（1）。
- **预期**：门控的 SDS 提升这几类的 CLIP-D；不门控的 C5 让 mask 扩张（mean(m) 上升），背景 PSNR 下降。

## 5. 第 2 步：指标效度（原 P3e-E1，与第 1 步并行）

在 540 张图（类别 0–7）上，λ ∈ {0.5, 1, 2}：

| 对照 | 构造 | 有效时的预期 |
|---|---|---|
| E1a 错 prompt | 用另一张图的目标 prompt 算残差（随机置换，排除同类别），评测时仍用本图正确的 prompt 对。需要新前向，540×2 次 | 每单位幅度的 CLIP-D 接近 0 |
| E1b 纯噪声 | δ = λ·\|R₀\|(p)⊙ξ，ξ 为标准高斯，与 R₀ 同包络、同范数 | 接近 0 |
| E1c 反向 | δ = −λ·R₀ | 为负 |

**判定**：E1a 和 E1b 每单位幅度的 CLIP-D 都 < V0 的 25%，且 E1c 为负，则 CLIP-D 判为有效；否则判为"幅度计"，第 1 步的语义匹配改以 E1d 为准。

**E1d 独立评委**（无论 E1a–c 结果如何都做；在第 1 步完成后进行）：
- 200 张评测图，在 CLIP-D = 0.040 下取以下各点：V0、V12、C8 和 Main 各自的最佳 K，再加 V2（λ=1）；
- 用本地开源 VLM（如 Qwen2.5-VL-7B）问两个问题："是否完成了〈编辑指令〉"（是/否）、"被编辑物体以外的部分是否保持不变"（1–5 分）；
- 报告各点的成功率和平均分，附 bootstrap CI。
