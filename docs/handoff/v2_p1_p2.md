## 0. 一句话目标

在真实模型（SD-Turbo）上检验理论给出的两个预测：

- **P1 光晕**：一步编辑的残差会在被编辑物体外侧产生一圈**与编辑方向相反**的偏移。
- **P2 推多远**：一步编辑系统性地编辑不足。把同一残差做不动点（Picard）迭代，在相同 CLIP-Edited 下，背景保持应当优于简单地把残差乘一个标量 λ。

两个实验**都不用任何 mask 来生成编辑**。GT mask 只用于评测和划定统计区域。

## 1. 背景：只需要理解这些

设 latent 为 $x$（SD-Turbo：4×64×64）。前向加噪 $z=a_t x+b_t\varepsilon$，噪信比 $\nu=b_t^2/a_t^2$。条件去噪器给出 $\hat\mu_c(z)=\mathbb E[x_0\mid z,c]$。

- **朴素残差**（FlowEdit 和 ChordEdit 的核心，共享同一个 $\varepsilon$）：
  $$R(x)=\hat\mu_{\rm tar}(a x+b\varepsilon)-\hat\mu_{\rm src}(a x_s+b\varepsilon).$$
- **一步编辑**：$x=x_s+\lambda R(x_s)$。
- **Picard 迭代**（固定 $\varepsilon$；源分支始终在 $x_s$ 处查询，只需算一次）：
  $$\delta_0=0,\qquad \delta_{n}=R(x_s+\delta_{n-1}),\qquad x^{(K)}=x_s+\delta_K .$$
  理论上，它的不动点是 DDS 目标的最小点，也就是自然梯度意义下的完整编辑。

理论依据是高斯模型 $p(x|c)=\mathcal N(\mu_c,\Sigma)$，其中 $W=\Sigma(\Sigma+\nu I)^{-1}$：

- $R(x_s+\delta)=(I-W)\Delta\mu+W\delta$。因此一步只完成了 $(I-W)$ 那一部分，高方差（低频、语义）方向编辑不足；Picard 迭代收敛到 $\Delta\mu$。
- 当 $\Sigma$ 是正相关的平滑核时，$-W\Delta\mu$ 会在编辑区域外侧产生一圈反号光晕。这就是 P1 要检验的预测；它应当随 Picard 迭代逐渐消失（P1c）。
- $t$ 越小，$\nu$ 越小，$W$ 越接近 $I$，一步编辑越不足、光晕相对越强，Picard 迭代的收益也越大（H1b、H2d）。

已在 toy 上确认的现象（作为参考，不用你复现）：高斯场在 t=0.9 时，一步完成度为 0.83，外环光晕均值为 −0.077，Picard 迭代 3 次后为 +0.010。

## 3. P1：光晕检验

### 3.1 计算内容

- **网格**：700 张图 × $t\in\{0.9, 0.7, 0.5\}$ × seed ∈ {0, 1, 2, 3}。每个点计算一次 $R=R(x_s)$（2 NFE），保存为 fp16。
- **latent mask**：把 GT mask（512²）做 8×8 平均池化，大于 0.5 记为内部，得到 $I$（64²）。用欧氏距离变换得到外部各像素到 $I$ 的距离 $d$（单位：latent 像素）。
- **距离带**：$(0,2]$、$(2,4]$、$(4,6]$、$(6,10]$、$(10,\infty)$。**主检验带是 $(2,6]$**。
- **统计量** $\rho_{\rm band}$：
  - 令 $u=\mathrm{blur}_\sigma(R\odot I)$，即逐通道的 Gaussian blur，只对内部残差做，$\sigma=3$（latent 像素）为主设置，$\sigma=1.5$ 作为副设置。
  - $\rho_{\rm band}=\cos(R|_{\rm band},\,u|_{\rm band})$，在该带内所有像素和 4 个通道上展平后计算余弦。
  - **预测**：$\rho<0$。
- **零假设对照** $\rho^{\rm null}$：
  - 对每张图，把 mask 平移到 20 个随机位置，要求平移后的内部区域不与原 mask 外扩 6px 后的区域重叠，且不越出画面（找不到合法位置时记 NaN）。
  - 用同一个 $R$ 计算同一统计量，取 20 个结果的平均。
  - 它衡量的是"残差自身的空间平滑性导致的正相关基线"。
- **相对光晕能量**：$e_{\rm rel}=\|R|_{(2,6]}\|^2/\|R|_I\|^2$（按像素数归一化后的均方比值）。
- **P1c**（数据来自 P2 的 latent，不需要另算）：对 Picard 的 $\delta_K$，$K\in\{1,2,3,4,6\}$，计算同样的 $\rho_{(2,6]}$。
- **排除规则**：主分析排除类别 8 和 9（mask 是全局或背景），以及 latent 内部面积超过 50% 或主检验带像素数少于 50 的图。被排除的样本也要输出，标注 `excluded=1` 并写明原因。

### 3.2 预注册假设与判定规则（看到数据之前就固定，不允许事后修改）

- **H1（主假设，t=0.9，σ=3，带 (2,6]，对 4 个 seed 取平均）**
  - SUPPORTED：$\mathrm{median}(\rho)<0$，Wilcoxon 符号秩检验 p<0.01；**并且** $\mathrm{median}(\rho-\rho^{\rm null})<0$，p<0.01。
  - REFUTED：$\mathrm{median}(\rho-\rho^{\rm null})>0$，p<0.01。
  - 其他情况：INCONCLUSIVE。
- **H1b**：$e_{\rm rel}$ 的中位数随 $t$ 减小而增大（0.9 < 0.7 < 0.5）。对相邻两档的配对差做 bootstrap 95% CI，CI 不含 0 记为 SUPPORTED。
- **H1c**：$\mathrm{median}(\rho_{K=4}-\rho_{K=1})>0$，即光晕随迭代减弱（p<0.01）。

每个结论都要同时给出：中位数、均值、bootstrap 95% CI（1000 次，以图为单位重采样）、p 值、样本数。

## 4. P2："推多远"检验

### 4.1 方法网格

所有方法都从同一个 $x_s$、同一个 $\varepsilon$ 出发。

| 方法 ID | 定义 | 参数 | NFE |
|---|---|---|---|
| `recon` | $x=x_s$（只做 VAE 重建） | — | 0 |
| `lam` | $x=x_s+\lambda R(x_s)$ | λ ∈ {0.5, 1, 1.5, 2, 2.5, 3} | 2 |
| `picard` | $x=x_s+\delta_K$（定义见 §1） | K ∈ {1, 2, 3, 4, 5, 6}，一次运行内保存每个前缀 | 1+K |
| `avg` | $x=x_s+\lambda\bar R_K$，$\bar R_K$ 为 K 个独立 $\varepsilon$ 下 $R(x_s)$ 的平均 | K ∈ {2, 4, 6}，λ ∈ {1, 2} | 2K |

- `avg` 是**方差缩减对照**，用来排除"Picard 的收益只是多次评估带来的平均效应"这种解释。
- `picard` 中 K=1 必须与 `lam` 中 λ=1 **逐元素相同**（测试 T-E2）。

**两种出图方式**（独立因子）：
- `raw`：直接解码 $x$。**主分析用 raw。**
- `prox`：先做一次目标分支的 Tweedie 投影 $x\leftarrow\hat\mu_{\rm tar}(a_c x+b_c\varepsilon_c)$，$t_c=0.3$，$\varepsilon_c$ 用独立的 seed（ChordEdit 风格），再解码。作为副分析。

**跑哪些**：
- $t\in\{0.9, 0.7, 0.5\}$，seed=0 全部跑完。
- $t=0.9$ 额外跑 seed=1，用来估计 seed 方差。

### 4.2 记录的量

- **PIE 官方指标**：Structure Distance，非编辑区（1−mask）上的 PSNR、LPIPS、MSE、SSIM，CLIP-Whole，CLIP-Edited。
- **latent 诊断**：
  - 内部均方位移 `delta_in`、外部均方位移 `delta_out`、`delta_ring`（(2,6] 带）；
  - Picard 收缩比 $c_n=\|\delta_n-\delta_{n-1}\|/\|\delta_{n-1}-\delta_{n-2}\|$（n≥2）；
  - 发散标记 `diverged`：存在 n 使 $\|\delta_n\|>5\|\delta_1\|$，或连续两次 $c_n>1$。**只标记，不截断。**
  - 光晕统计 $\rho_{(2,6]}$（供 P1c 使用）。

### 4.3 预注册假设与判定规则

- **H2a（编辑不足，t=0.9）**：CLIP-Edited(K=3) − CLIP-Edited(K=1) 的配对 bootstrap 95% CI > 0 记为 SUPPORTED；同时报告 `delta_in` 随 K 的变化。
- **H2b（Pareto，主假设，t=0.9，raw）**：
  - 把 `lam` 的 6 个点按平均 CLIP-Edited 排序，得到一条分段线性的 PSNR(CLIP) 曲线。
  - 对 K ∈ {2, 3}，计算 $\Delta\mathrm{PSNR}_K=\mathrm{PSNR}_K-\mathrm{PSNR}_{\lambda\text{-curve}}(\mathrm{CLIP}_K)$。
  - 如果 $\mathrm{CLIP}_K$ 落在 λ 曲线的 CLIP 范围之外，记为 `out_of_range`，**不允许外推**。
  - 用 bootstrap（1000 次，以图为单位重采样，每次两条曲线都重新计算）求 95% CI。
  - SUPPORTED：两个 K 的 CI 都 > 0。REFUTED：两个都 < 0。其他情况：INCONCLUSIVE。
  - 用同样方法报告 ΔLPIPS、ΔStructDist，以及 `avg` 对 λ 曲线的同类比较。
- **H2c（收敛）**：报告 $c_n$ 的中位数和四分位数、`diverged` 的比例，并按类别分组。不做判定。
- **H2d**：t=0.7 的 $\Delta\mathrm{PSNR}_{K=3}$ 大于 t=0.9 的（配对差的 CI > 0）。如果 t=0.7 落在 out_of_range，改用 CLIP 增益 (K3 − K1) 来比较，并说明。

### 4.4 健全性门槛（不通过就停下来排查，不要继续跑）

- `lam` λ=1 + `prox` 在 t=0.9 时，PIE 全集的 PSNR 应在 [20, 27]，CLIP-Edited 应 ≥ 20。参照：ChordEdit 的 PSNR 在 22–24 之间，它用的弦残差和我们的单 $R$ 不完全相同，所以只要求同一量级。超出这个范围几乎肯定是 $\hat x_0$ 换算、latent 缩放或 prompt 处理有问题。
- `recon` 的 PSNR 应明显高于所有编辑方法。这是 VAE 重建的上限，报告中要列出来。

| T-E4 | 线性玩具：把去噪器替换成高斯解析去噪器 $\hat\mu(z)=\mu+W(z/a-\mu)$（W 为对角阵，取值在 (0,1)） | Picard 误差等于 $W^K\Delta\mu$，误差 < 1e-6 |
| T-H1 | 合成光晕：$R=$ 内部 bump $-0.1\cdot\mathrm{blur}(\text{bump})$ 外溢到外部 | ρ < −0.5 |
| T-H2 | 白噪声 $R$（100 次） | ρ 的均值的绝对值 < 0.05 |
| T-X1 | 输出图等于源图 | PSNR = inf（或报告上限），LPIPS 接近 0，Structure Distance 接近 0 |
| T-X2 | 与官方评测脚本对比，20 张图 | 各指标的最大绝对差 < 1e-4 |
| T-S1 | bootstrap：已知均值的合成数据 | 95% CI 覆盖率在 [0.93, 0.97]（200 次重复） |
| T-S2 | 插值：单调 λ 曲线和越界点 | 正确插值，正确返回 out_of_range |

## 8. 纪律

1. **不调参**：§3.2 和 §4.3 中的阈值、距离带、σ、方法网格在看到结果后都不能改。如果你认为某项设置明显不合理，写进 DEVIATIONS 并**同时**报告原设置和新设置下的结果。
2. **不删样本**：排除只按 §3.1 的规则进行，所有样本都要出现在 CSV 中。
3. **不挑 seed**：所有 seed 的结果全部报告。
4. **负结果同样重要**：REFUTED 是有价值的结论，原样报告即可。
5. 遇到发散、NaN 或指标异常，先在报告的 Anomalies 一节记录，然后继续跑完其余部分（§4.4 的健全性门槛除外，它是硬停止条件）。
