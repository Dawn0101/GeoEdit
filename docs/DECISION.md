## 1. 为什么停

1. **OT 是装饰性的。** 方法只用了传输计划的边际 `σ`，计划本身被丢掉；`ε→0` 时
   `σ_j ≈ 1[min_o(‖f_j−g_{j+o}‖²/s_f² + ‖o‖²/s_p²) < 2τ]`，即带位移容差的块匹配变化检测。
   把"部分 OT"换成"窗口最小距离阈值"不需要改任何其它部分。
2. **E1 证明空间容忍没有余量。** 背景残差里刚性平移能解释的部分：B0 显著位移 patch 占
   0.03%，B1 占 1.58%，`gain` 中位数与 p90 均为 0.000；且残差 85–93% 在高频，不是低频漂移。
   偏差本质是**纹理重绘**，空间代价无从发挥。
3. **逐点阈值同样不可分。** 面积匹配 GT 时背景误判率 32.7%（B0）/ 17.5%（B1），
   与 σ 直接得到的 IoU ≈ 0.41 一致 —— 背景与编辑区在"残差幅度"上不可分。
4. **指标口径对 mask 方法有利。** PIE-Bench 的背景指标先把两张图乘 mask 再按全图算 PSNR，
   对任何 mask 方法有约 `−10·log10(背景占比)` dB 的固定加成；与 ChordEdit/FlowEdit 这类
   无 mask 方法比 PSNR 不公平。
5. **超参数量翻倍**（τ, s_p, R, ε, blur, 特征, s_f 的分位数, iters/tol），且在测试集上扫参。

## 4. 对后续方法的输入

- **不要**在"编辑区域估计"这个模块上做增量，除非新方案的收益不能由一个 mask 消融复现。
  及格线是：求解出的对象必须改变传输路径本身（PreciseEdit 一类的方向），而不是事后混合。
- 任何新方法都必须先跑 **B0/B1 基线 + E1 诊断**再决定赌注；`cache/` 和 `results/E1/` 可直接复用。
- **CLIP 分数不可跨论文比较**：同一张图、同一权重，输入标度从 0–255 换成 0–1 会让分数从
  27.39 掉到 17.52。只有 PSNR / LPIPS / SSIM / Structure Distance 能跨论文对齐。
